## 📍 About Me

I'm a **B.Tech Computer Science & Engineering** student currently working as a **Software Developer Intern at Emagic Solutions Pvt. Ltd.**, building with **React Native** and **FastAPI**.

I spend most of my time at the intersection of three things I genuinely enjoy — **software development**, **data analytics**, and **artificial intelligence**. I like understanding how systems are built end-to-end, from a mobile interface down to the API layer, and I'm equally drawn to what happens *after* the data is collected — finding patterns in it, visualizing it, and using it to make better decisions.

On the AI side, I'm actively exploring **Generative AI** and **Agentic AI** — experimenting with LLM APIs, retrieval-based systems, and wiring language models into real applications rather than using them only as chatbots.

I'm not chasing one narrow label — I'm building toward being a well-rounded engineer who moves comfortably between an app's frontend, its backend, its data, and the intelligence layered on top of it.

## 📊 Data Analytics

I treat data as more than numbers in a spreadsheet — it's a starting point for a question. Right now I'm actively developing my ability to:

- Explore and clean raw datasets
- Find patterns and relationships worth paying attention to
- Build clear, honest visualizations rather than charts for their own sake
- Query and shape data with **SQL**
- Turn analysis into insight that can actually inform a decision

This is a space I'm still growing in, not one I claim to have mastered — but it's a core part of how I want to build software going forward.
